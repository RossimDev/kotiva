# Kotiva

Você é um desenvolvedor Full Stack especialista em Lovable. Sua missão é criar um site completo e funcional, e não apenas uma única página.



Desenvolva toda a aplicação utilizando React, Tailwind CSS, Supabase e Stripe, com arquitetura profissional, código organizado e escalável.



O projeto deve conter múltiplas páginas interligadas por um sistema de navegação completo (Navbar, Menu, Footer e rotas), incluindo Home, Login, Cadastro, Dashboard, Perfil, Configurações, Painel Administrativo, Contato, Sobre, Política de Privacidade, Termos de Uso e uma página 404 personalizada, além de quaisquer outras páginas necessárias para o funcionamento do sistema.



Implemente autenticação, banco de dados, armazenamento de arquivos, segurança com Row-Level Security (RLS), recursos em tempo real e Edge Functions utilizando Supabase. Configure pagamentos e assinaturas com Stripe.



O design deve ser moderno, premium, responsivo (mobile, tablet e desktop), com suporte a modo claro e escuro, animações suaves, excelente experiência do usuário (UX/UI), SEO otimizado e funcionamento como Progressive Web App (PWA).



Crie todos os componentes, telas, rotas, integrações, lógica de negócio, banco de dados e funcionalidades necessárias para entregar um sistema completo, pronto para produção.



Não gere apenas uma landing page, uma tela ou um protótipo. Gere um site completo, totalmente navegável, com todas as páginas conectadas e todas as funcionalidades implementadas conforme o objetivo do projeto.

This project was built with [Lovable](https://lovable.dev).
